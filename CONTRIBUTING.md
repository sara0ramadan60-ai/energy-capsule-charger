# Contributing to Energy Capsule Charger

Thank you for your interest in contributing! This project aims to revolutionize EV charging with ultra-fast energy capsule technology.

## How to Contribute

### 1. Report Bugs
- Open an issue with the `bug` label
- Include steps to reproduce, expected behavior, and actual behavior
- Share system/environment details

### 2. Suggest Features
- Open an issue with the `enhancement` label
- Describe the feature, why it's useful, and how it should work

### 3. Submit Code
1. Fork the repository
2. Create a branch: `git checkout -b feature/your-feature`
3. Make your changes
4. Run tests: `pytest`
5. Commit: `git commit -m "Add your feature"`
6. Push: `git push origin feature/your-feature`
7. Open a Pull Request

### 4. Improve Documentation
- Fix typos, clarify explanations, add examples
- Translate docs to other languages

## Code Style
- Python: Follow PEP 8
- Markdown: Use proper formatting, one line per sentence
- Hardware docs: Include diagrams where helpful

## Pull Request Guidelines
- Keep PRs focused on a single change
- Add tests for new functionality
- Update documentation if needed
- Ensure CI passes

## Need Help?
Open a discussion or issue — we welcome all contributors!
